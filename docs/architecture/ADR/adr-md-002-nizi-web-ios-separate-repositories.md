# ADR-MD-002: Nizi Web and Nizi iOS are separate repositories

**Status:** Accepted

**Decision:** `nizi-web` and `nizi-ios` are independent repositories/apps with their own release cycles.

**Context:** Nizi Web owns accounts, Album, sharing and server data; Nizi iOS owns on-device library access, discovery, and upload handoff. See [ARCHITECTURE.md § System context](../ARCHITECTURE.md#1-system-context).

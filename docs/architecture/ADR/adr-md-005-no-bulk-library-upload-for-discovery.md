# ADR-MD-005: No bulk upload of the library for discovery

**Status:** Accepted

**Decision:** The discovery/survey process never uploads the library (or thumbnails, GPS, analysis data) to Nizi's servers. Upload only happens once the user confirms an Album.

**Context:** Core privacy boundary — see [PRODUCT-PHILOSOPHY.md § Local-first](../../philosophy/PRODUCT-PHILOSOPHY.md#2-local-first) and the privacy boundary in [modules/memory-discovery/ARCHITECTURE.md § 11](../../modules/memory-discovery/ARCHITECTURE.md).

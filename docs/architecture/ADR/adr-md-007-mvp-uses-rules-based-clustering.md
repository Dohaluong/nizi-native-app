# ADR-MD-007: MVP uses rules-based clustering

**Status:** Accepted

**Decision:** Event discovery in the MVP uses explainable, rule-based temporal/spatial clustering and scoring — no ML model.

**Context:** See [PRODUCT-PHILOSOPHY.md § Progressive intelligence](../../philosophy/PRODUCT-PHILOSOPHY.md#5-progressive-intelligence). AI/Vision-based analysis is added later, once the rules-based core is stable (Phase 3+ in [modules/memory-discovery/SPEC.md](../../modules/memory-discovery/SPEC.md)).
